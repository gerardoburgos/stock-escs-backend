# Stock_escs - API REST - Gerardo Burgos Martinez

API REST para la gestión de usuarios e inventario desarrollada con Node.js, Express y MySQL.

## Características
- Seguridad de contraseñas con **Argon2id**.
- Validación de datos con **express-validator**.
- Consultas SQL parametrizadas.
- Documentación interactiva con **Swagger (OpenAPI 3.0)**.

## Instrucciones de Inicio
1. Ejecutar `npm install` para instalar las dependencias.
2. Importar el archivo `schema.sql` en MySQL.
3. Iniciar el servidor con `npm start`.
4. Acceder a la documentación en `http://localhost:3000/api-docs`.
